This is the Weapons Adjustment Mod for You Are Empty, by O. Kaya.

The goal was to adjust some gripes with the game's weapons handling/balance for a better QOL while playing. The philosophy was to throw in certain buffs to make some weapons that are normally clunky/weak more usable, and occasionally more realistic in small ways to add to immersion. Feel free to suggest changes to this or make your own variants, though if you're basing off my variant, please credit me. This was based off the info provided by this steam guide: https://steamcommunity.com/sharedfiles/filedetails/?id=3829777330.

It was developed on the Steam version of absolute edition, and I cannot guarantee any compatibility with any other variant.
If you wish to thank me, wishlist my game, HRSPWR @ https://store.steampowered.com/app/3714900/HRSPWR/

INSTALL INSTRUCTIONS:
- Drop the prototypes "prototypes" into '[You Are Empty Folder]/gameres/scripts/you_are_empty
- Let it replace files in the prototypes folder when prompted.
- Run your game

CHANGES LIST:
- Player: Sprint went from 260->300, base speed 200->240, jump 80->90, strafe/backwards speeds were made lower than the forward speed. You overall move slightly faster in every case. If you don't want these changes, you can skip the actors part of the prototypes folder, and you'll retain default movement.
- Spanner: Now full auto with 1.5x range. No extra dps, just easier to actually confirm hits with and avoids carpal tunnel.
- Mauser c96: Now holds an accurate 10 rounds with 50 spare, and fires faster. Default firecap always felt a little too slow.
- Shotgun: Tighter spread, reduced damage, pellets from 5 to 9. Feels the same as stock but is a decent bit more consistent.
- Molotov: ~2x throw distance, ~1.5x radius, ~1.25x damage, 5->12 max ammo. Should make it harder to nuke yourself, and more consistent against enemies.
- PPSH: ROF doubled. This gun fires way too slow in base game, and for such a legendary weapon, that felt off.
- Mosin: Spread 3->2, dropped rifle ammo 3->4. Now you can use this thing more, normally it has no ammo and the spread matches the (unaimed)c96.
- Sniper: Spread 3->1.5, zoom fov 45->30. Again, this thing was as inaccurate as the c96, and had the same amount of zoom. Fixed.
- Electric Gun: Damage 3.5->8. This thing never felt worth using, but not as bad as 3.5 damage, so I just gave it a bunch more damage in hopes of adding some consistency.
